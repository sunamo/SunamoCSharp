# SunamoCSharp

## Short description

Pomocné nástroje pro práci s C# zdrojovým kódem (parsování, generování), vyčleněné z monolitu SunamoDevCode. Obsahuje CSharpGenerator a CSharpHelper rozdělené do partial souborů. Balíček je samostatný, potřebný kód z dříve referencovaných balíčků má jako internal v _sunamo. Součástí jsou testy a Runner projekt.
